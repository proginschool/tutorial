1 Цикл while

Повторюй, поки умова істинна

C++ перевіряє умову while перед кожним повторенням. Команди циклу беруться у фігурні дужки { }. Змінюй значення, від якого залежить умова, інакше цикл може не завершитися.

#include <iostream>

int main() {
    int counter = 1;
    while (counter <= 3) {
        std::cout << counter << '\n';
        ++counter;
    }
    return 0;
}

std::cin читає дані, а std::cout виводить їх. У прикладі counter збільшується на 1 після кожного кроку.

                Цикл for
            

            

                

                    
Керуй кількістю повторень

                    
У циклі for (ініціалізація; умова; крок) спочатку створюється лічильник, потім перед кожним кроком перевіряється умова, а після тіла виконується крок. За умови i < stop число stop не входить у послідовність.

                    
#include <iostream>

int main() {
    for (int number = 1; number < 5; ++number) {
        std::cout << number << '\n';
    }
    return 0;
}

                    
На відміну від Python, у C++ немає вбудованої range(): початок, межу й крок задають у заголовку циклу.

                3
                Керування циклом
            

            

                

                    
Зупиняй і пропускай

                    
break завершує найближчий цикл, а continue пропускає решту поточного повторення й переходить до наступного. У вкладених циклах ці команди діють лише на найглибший цикл.

                    
#include <iostream>

int main() {
    for (int number = 1; number < 8; ++number) {
        if (number == 3) {
            continue;
        }
        if (number == 6) {
            break;
        }
        std::cout << number << '\n';
    }
    return 0;
}

                    
Приклад виведе 1, 2, 4, 5: число 3 пропускається, а на числі 6 цикл завершується.

Скомпілюй приклад і перевір, яке число пропускається та на якому цикл зупиняється.
