1 Знайомство з `if` (Якщо)

🧠 Теорія: Життєва аналогія

У житті ми постійно ставимо умови: "ЯКЩО йде дощ ➔ беремо парасольку". У Python для цього є команда if (з англ. "якщо").

Правило запису:

  • if умова: # Двокрапка обов'язкова!
  •     команда # Відступ (4 пробіли) показує, що команда всередині if

2 Альтернатива `else` (Інакше)

🧠 Теорія: Що, якщо ні?

Аналогія: "ЯКЩО є гроші ➔ купуємо снек, ІНАКШЕ ➔ йдемо додому". Слово else обробляє всі інші випадки, коли умова if виявилася брехнею.

Важливо: else пишеться з нового рядка, БЕЗ відступу (на одному рівні з if), і теж має двокрапку в кінці!

🐞 Знайди помилку

Хтось написав код, але забув про відступ для команди всередині else. Виправ код у редакторі (додай 4 пробіли перед другим print) і натисни перевірити.

2. З яким відступом пишеться саме слово else: ?

💻 Практика 1: "Перепустка"

Програма отримує вік: vik = int(input()). Якщо вік 18 або більше (>= 18), виведи "Вхід дозволено", інакше виведи "Вхід заборонено".

💻 Практика 2: "Парне чи Непарне?"

Щоб перевірити, чи ділиться число на 2 без остачі (тобто чи є воно парним), у Python використовують оператор % (остача від ділення).

Умова: if num % 2 == 0:

Зчитай число num. Якщо воно парне — виведи "Парне", інакше виведи "Непарне".

3 Багато варіантів `elif`

🧠 Теорія: Якщо, А якщо, Інакше

Коли варіантів більше ніж два (наприклад, оцінки чи кольори світлофора), використовують elif (скорочення від else if - "інакше якщо"). Їх може бути скільки завгодно!

Також можна об'єднувати умови:
and (і) - вимагає, щоб обидві умови були правдою.
or (або) - достатньо, щоб хоча б одна умова була правдою.

🕵️ Трасування (читання коду)

m = 10
if m == 1 or m == 2 or m == 12:
    print("Зима")
elif m >= 3 and m <= 5:
    print("Весна")
elif m >= 6 and m <= 8:
    print("Літо")
else:
    print("Осінь")

📝 Експрес-тест

1. Для чого потрібна команда elif?

2. Якщо ми пишемо умова1 and умова2, коли виконається код?

💻 Практика 1: "Оцінка"

Зчитай бал: bal = int(input()).
Якщо бал >= 10 — виведи "Високий".
Якщо бал >= 7 і (and) бал < 10 — виведи "Достатній".
Інакше — виведи "Треба попрацювати".

💻 Практика 2: "Світлофор"

Зчитай колір: color = input() (просто текст).
Якщо color == "червоний" ➔ виведи "Стій".
А якщо (elif) color == "жовтий" ➔ виведи "Увага".
А якщо (elif) color == "зелений" ➔ виведи "Йди".
Інакше ➔ виведи "Зламався".

4 Продвинутий рівень

🧠 Теорія: Вкладені розгалуження (`if` всередині `if`)

Іноді нам потрібно перевірити умову тільки після того, як інша умова вже виявилася правдою. Це наче фейс-контроль на закриту вечірку:

  • Спочатку охоронець перевіряє: "Чи є ви у списку гостей?" (Перший if).
  • ТІЛЬКИ якщо ви у списку, він перевіряє далі: "Чи є вам 18 років?" (Другий, вкладений if).

Головне правило в Python для вкладених умов — додатковий відступ. Кожен новий рівень всередині вимагає ще 4 пробіли (разом 4 + 4 = 8 пробілів). Це візуально показує комп'ютеру, що команда знаходиться "всередині всередини".

if у_списку == "так":
    print("Ви є у списку!") # 4 пробіли
    if вік >= 18:
        print("Вхід дозволено!") # 8 пробілів!
    else:
        print("Вибачте, ви ще малі.") # 8 пробілів!
else:
    print("Вас немає у списку.") # 4 пробіли

📝 Експрес-тест

1. Скільки пробілів має бути перед командою, яка знаходиться всередині `if`, який сам знаходиться всередині іншого `if`?

💻 Практика 1: "Логін і Пароль"

Напиши вкладену перевірку:

  1. Зчитай логін: log = input() (без int, бо це текст!).
  2. Якщо логін "admin", зчитай пароль: pas = input().
    • Якщо пароль "1234", виведи "Суперсекрет".
    • Інакше (це `else` до внутрішнього `if`) виведи "Невірний пароль".
  3. Інакше (це `else` до зовнішнього `if`) виведи "Невідомий користувач".

💻 Практика 2: "Кінотеатр"

Зчитай вік: age = int(input()).
Якщо вік >= 12, то спитай тип квитка: ticket = input().
    Якщо ticket == "VIP", виведи "Супер зал".
    Інакше виведи "Звичайний зал".
Інакше (якщо вік < 12) виведи "Мультики".
